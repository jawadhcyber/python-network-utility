# Python Network Utility

A beginner-friendly Python utility for checking basic network
connectivity to an IP address or hostname.

## 🎯 Project Purpose

This project was created to practice Python programming and
networking fundamentals as part of my cybersecurity learning journey.

## 🛠️ Technologies

- Python
- Basic networking
- IP addresses
- Hostnames
- Git/GitHub

## 🔍 Features

- Accepts an IP address or hostname
- Performs a basic connectivity check
- Reports whether the host is reachable
- Works on Windows, Linux, and macOS

Make sure Python is installed.

Run:
